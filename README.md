# SKYBOUND · 通用机动飞行实验室

独立访问地址：https://my-85.github.io/skybound-entry/?scene=valley-inspection

本仓库直接托管可交互的实验室网页，不会跳转到其他网站。

## 可用功能

- 八个预设场景及其原有真实飞行记录。
- 三维回放、镜头切换、不同机型外观与学生/教师记录对照。
- 障碍物、航点和目标速度编辑，撤销、项目导入与保存。
- Tacview ACMI 及完整场景 ZIP 导出。

## 在线重算

GitHub Pages 版本尚未接入独立计算后台。编辑路线后，页面会撤销旧路线的飞行结果，允许预览参考路线、保存项目或导入匹配的真实计算结果。页面不会将几何预览冒充为控制器飞行结果。

## 更新网页

修改 `main` 分支中的网页文件后，GitHub Pages 会自动发布。完整后台源码另外保存在所有者的私有仓库中。
